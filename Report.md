```cpp
    cout << "Исходное число:" << endl;
    cout << "Десятичный вид: " << number << endl;
    cout << "Бинарный вид:   " << std::bitset<32>(number) << endl;
    number = number + 1;

    cout << "Результат после прибавления 1:" << endl;
    cout << "Десятичный вид: " << number <<endl;
    cout << "Бинарный вид:   " << std::bitset<32>(number) << endl;

    return 0;
}
```

Тип данных int имеет длину ровно 32 бита, 1 бит занят знаком числа +(0) или -(1)  максимальное возможное положительное число 2 147 483 647 которое можно втиснуть в 32 бита 
и это выглядит как 01111111111111111111111111111111 когда мы прибавили 1 в конце получился 0 и следующая 1 перешла дальше и так до самого начала, из-за чего знак сменился на -

```cpp

    std::cout << "Мантисса: " << std::bitset<23>(bits) << std::endl;
}
```

### Ответ:
Мантиссы не являются красивыми тк не заканчиваются на нули. Компьютер хранит эти числа с микроскопической погрешностью (он их обрезает и округляет).
Именно поэтому, если в программе сложить 0.1 + 0.2, результат из-за этих округлений получится не 0.3, а что-то вроде 0.30000001.

## Контрольные вопросы

1) Позиционная система счисления — это система, в которой значение каждой цифры зависит от её позиции в числе.
305, 3 - позиция сотен, 0 - позиция десятков, 5 - позиция единиц
2)Внутри компьютера миллиарды крошечных транзисторов, которые работают как обычные выключатели света.
Реализовать электронную схему, которая четко различает всего два состояния — «тока нет» (0, выключено) и «ток есть» (1, включено) — технически невероятно просто и надежно.
3)Разбиваем двоичное число справа налево на группы по 4 бита и заменяем каждую группу по таблице (от 0 до F). Например 11010110 бьем на группы 1101 и 0110 ,
1101 - это 13(буква D), 0110 - это 6, получается D6, это быстрее и легче чем высчитывать остатки при переводе в десятичную
4) 5 в двоичном коде это 0000 0101 , инвертируем - 1111 1010, добавляем единицу 1111 1011.
6)Число 2147483647 — это максимум для 32-битного знакового int. Его биты: 01111111 11111111 11111111 11111111 (первый бит 0 — знак плюса).
Когда мы прибавляем 1, по цепочке переносов в столбик все единицы обнуляются, а единица переноса влетает в самый первый, знаковый бит.Получается: 10000000 00000000 00000000 00000000.
8) компьютер не может хранить бесконечные дробные числа, поэтому он их обризает и округляет, из-за чего есть небольшая погрешность.
9)ASCII — это очень старый и маленький стандарт кодирования (7-8 бит на символ). Он может вместить всего 128 (или 256 в расширенной версии) символов.
Этого хватает только на английский алфавит, цифры и базовые знаки препинания. Любые другие языки туда физически не влезают.
Unicode — это современный всемирный стандарт.Он не ограничен одним байтом и способен закодировать более 140 000 символов.
В него одновременно помещаются алфавиты всех языков мира (включая русский, китайские иероглифы, мертвые языки вроде египетских иероглифов),
а также математические знаки и все существующие эмодзи.
